## About Me

I'm **Md Abid Hasan Plabon**, a full-stack developer and Computer Science student at **Jahangirnagar University**, Dhaka. I enjoy building end-to-end web applications — from polished user interfaces to reliable APIs and databases.

I work primarily with the **MERN stack**, and I'm also experienced with **Next.js**, **Nest.js**, and both **MongoDB** and **PostgreSQL**. I'm always looking to learn, ship meaningful projects, and collaborate on open-source work.
